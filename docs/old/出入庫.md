重點在要能找出
1. 模型錯在哪
	沒找到
	找錯位置
	分錯類

2. 分離工作流程/改善模型
	不要打斷員工主要的目的(出入庫就出入庫，不要同時改善模型)

3. 人工判斷錯誤
	代表訓練資料可以加強這部分

4. 確保能找出錯誤，不要影響庫存正確性
