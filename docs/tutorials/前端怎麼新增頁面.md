# 前端:怎麼新增頁面


1. 修改前，同步本地main、切新分支

分支名稱代表要改什麼，比如要新增"物品設定頁面"，叫做`add-item-setting-page`

```bash
git checkout main
git pull
git checkout -b add-item-setting-page
```

2. 檢視頁面模板

在`inventory/app/frontend/pages/`放的都是頁面模板(還沒有資料的骨架)

目前已經有`items/[id]/page.html`，代表URL如果是`/items/數字id`，就會開啟這個頁面

會先繼承全站通用模板(處理全站javascript和css挹注)

然後複寫模板中的區塊，顯示客製資料

```html
{% extends "base.html" %}
{% block title %}分頁的名字{% endblock %}
{% block content %}網頁內容{% endblock %}
```

3. 接受初始資料
後端會告訴前端初始資料的結構，比如這裡有兩種初始資料：item(檢視的物品，比如：卡片)、instances(此物品的視覺變體，比如：卡片的正面反面)

```json
{
  "item": {
    "id": 6,
    "name": "卡片",
    "category": null,
    "min_stock": 3,
    "recognition_entity_id": 11,
    "created_at": "2026-09-18T08:54:41"
  },
  "instances": [
    { "id": 14, "name": "正面", "sample_count": 1 },
    { "id": 15, "name": "背面", "sample_count": 1 }
  ]
}

```

前端要用模板語法把資料繪製到畫面上，模板語法就是html混合一些基本迴圈/條件。

```html
{% extends "base.html" %}
{% block title %}物品設定{% endblock %}
{% block content %}
  <h1>{{ item.name }}</h1>

  <ul class="result-list">
    <li>類別:{{ item.category or "未分類" }}</li>
    <li class="field">
      <label for="min_stock">最低庫存</label>
      <input type="number" id="min_stock" name="min_stock" min="0" value="{{ item.min_stock }}">
    </li>
    <li>建立時間:{{ item.created_at }}</li>
  </ul>

  <button type="button" class="btn btn-primary" id="save-btn" data-item-id="{{ item.id }}">儲存</button>
{% endblock %}


```

4. 從既有頁面連過去

剛才新增的頁面已經可以透過，`items/1`或`items/123`存取。

但通常網頁會從其他網頁連過去，比如：物品列表頁面中，點物品列表的物品，要連去剛才新增的頁面。

所以要在物品列表畫面`items/page.html`的每一列item加連結:

```html
<a href="/items/{{ item.id }}">{{ item.name }}</a>
```

5. 綁定js觸發客製化邏輯

在跟頁面模板同資料夾下，新增`script.js`

```js
(function () {
  const saveBtn = document.getElementById("save-btn");

  saveBtn.addEventListener("click", () => {
    alert("按下儲存了");
  });
})();

```

在頁面模板引用該腳本

```html
<script src="{{ url_for('items.static', filename='[id]/script.js') }}"></script>

```

6. 在客製邏輯中呼叫API
顯示頁面後，前端通常要傳訊息給後端，像是：修改資料，要透過發送符合規範的http請求達成。

這裡會發送修改物件資訊的請求，去改物件的最小庫存。

```js
(function () {
  const saveBtn = document.getElementById("save-btn");
  const minStockInput = document.getElementById("min_stock");

  saveBtn.addEventListener("click", async () => {

    const itemId = saveBtn.dataset.itemId;

    const resp = await fetch(`/items/${itemId}`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ min_stock: Number(minStockInput.value) }),
    });

    if (!resp.ok) {
      const data = await resp.json();
      alert(`儲存失敗: ${data.message || resp.status}`);
      return;
    }

    alert("已儲存");
  });
})();


```

7. 測試

修改後要重新build

```bash
docker compose up -d --build
```

要開啟網頁：

瀏覽器輸入`http://localhost:5000/items/`

8. 提交、push分支

```bash
git add .
git commit -m "功能：新增修改物品畫面"
git push -u origin add-item-setting-page
```

9. 開PR、merge

```bash
gh pr create
```

到GitHub上merge。

10. 回到main、清理分支

```bash
git checkout main
git pull
git branch -d add-item-setting-page
git push origin --delete add-item-setting-page
```
