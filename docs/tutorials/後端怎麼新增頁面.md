# 後端:怎麼新增頁面


1. 新增頁面

在`inventory/app/frontend/pages`新增`items/[id]/page.html`
```
{% extends "base.html" %}
{% block title %}物品設定{% endblock %}`        //改tab名字
{% block content %}還沒實作{% endblock %}`      //主要渲染內容
```
2. 定義頁面ROUTE

在`inventory/app/backend/routes/items.py`，綁定route到剛才的頁面，route的路徑是頁面url，`render_template`的路徑是頁面模板位置，相對於`inventory/app/frontend/pages`
```python
@bp.route("/items/<int:item_id>")
def item_detail(item_id):
    return render_template("items/[id]/page.html")
```

3. 挹注資料
```python
@bp.route("/items/<int:item_id>")
def item_detail(item_id):
    db = get_db()
    item = db.get(Item, item_id)
    instances = vision_client.get_instances(item.recognition_entity_id)
    return render_template("items/[id]/page.html", item=item, instances=instances)
```

4. 重啟
```bash
docker compose up -d --build
```
```bash
curl -s http://localhost:5000/items/1
```
