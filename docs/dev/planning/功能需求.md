
# 基本(已經能用)
以「倉庫庫存」為例。

| 功能 | 描述 | 狀態 |
|------|------|------|
| 操作者身分 | 追蹤使用者的身分、限制操作權限 | 未開始(0%)，可之後補 |
| 列出物品 | 列出所有物品，提供基本資訊和操作瀏覽連結(新增/修改/刪除/庫存異動) | 部分(70%)：列表、基本資訊已完成，缺刪除與庫存異動連結 |
| 新增物品 | 名稱/變體/樣本(變體可省) | 完成(100%) |
| 修改物品 | 名稱/變體/樣本(變體可省) | 部分(30%)：min_stock可改，改名稱/變體vision-service尚無對應API |
| 刪除物品 | | 部分(20%)：vision-service已有刪除entity/instance的API，inventory自己尚無刪除路由，也未決定軟/硬刪除 |
| 入庫 | 管理者選擇入庫功能，使用攝影機拍攝要入庫的物品，系統辨識物品種類與數量，使用者可以修改辨識結果，確認無誤後，系統更新庫存數量。 | 完成(100%) |
| 出庫 | 管理者選擇出庫功能，使用攝影機拍攝要出庫的物品，系統辨識物品種類與數量，使用者可以修改辨識結果，確認無誤後，系統更新庫存數量。 | 部分(50%)：辨識邏輯、前端畫面可與入庫共用，只差庫存增減方向的邏輯 |
| 盤點 | 攝影機定期統計當前庫存量，比對庫存資料，如果有錯，自動修正。 | 未開始(0%)：資料庫交易類型欄位需先擴充 |
| 庫存變化紀錄 | 顯示某物品入庫、出庫、盤點修正紀錄，提供操作時間、物品名稱、數量、使用者與操作類型。 | 部分(50%)：資料已在寫入，只差頁面和查詢API(還缺盤點修正類型) |

# 進階(完成基本再來做)(就算沒做也能交差)
| 功能 | 描述 | 狀態 |
|------|------|------|
| 首頁儀表板 | 最近庫存異動、低庫存清單 | 未開始(0%) |
| 標註後台儀表板 | 待處理辨識校正清單 | 未開始(0%) |
| 修正模型初判結果(標註) | 會追蹤辨識初始結果，提供人工精修標註介面，結案的標註可匯出作為訓練資料集。 | 部分(30%)：入庫當下修正已有，事後精修介面、樣本列表/圖片API皆缺 |
| 系統設定 | 攝影機自動定期盤點週期、模型精度等等 | 部分(20%)：vision-service已有設定API基礎，inventory自己的設定項目未做 |
| 低庫存提醒 | 物品低於最低庫存量時，系統顯示提醒。 | 部分(60%)：列表已有低庫存標記，缺主動提醒呈現 |
