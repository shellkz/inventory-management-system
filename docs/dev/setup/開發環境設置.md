# 開發環境設置

## 前置需求
先安裝下列程式：
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Git](https://git-scm.com/downloads)

## 設置步驟

## 複製專案
1. 切到想放專案的資料夾

在想放專案的資料夾空白處點右鍵，選「Open git bash here」，會看到終端啟動

2. 複製庫存管理系統

按照順序在終端執行：
```bash
git clone https://github.com/shellkz/inventory-management-system.git
```
3. 複製視覺辨識服務

按照順序執行：
```bash
cd inventory-management-system
git clone https://github.com/shellkz/sharingan-vision.git vision-service
```
4. 確定執行完長這樣：
```
inventory-management-system/
    其他東西
    vision-service/
```

## 下載模型
1. 在inventory-management-system下新增`models`資料夾

如果沒切換資料夾，繼續執行就好：
```bash
mkdir models
```
2. 到 https://github.com/shellkz/sharingan-vision/releases/tag/v0.1.0 下載這兩個模型檔案，放進`models/`:
- `FastSAM-s_640_fp32.onnx`
- `dinov2_vits14_batch_int8.onnx`

## 初始資料
1. 下載資料
https://drive.google.com/drive/folders/10i3yYmCEGkhFOBjhH7rQAo1gY2xABsHQ?usp=sharing
2. 解壓縮到`inventory-management-system`資料夾下

## 設定環境變數
1. 複製範例設置檔`.env.example`為正式設置檔`.env`

如果沒切換資料夾，繼續執行就好：
```bash
cp .env.example .env
```

2. 編輯正式設置檔`.env`，填入`VISION_API_KEY`

在Git Bash執行:
```bash
openssl rand -hex 32
```
把印出來的一長串文字貼到`.env`的`VISION_API_KEY=`後面。

## (非必要)IDE型別提示設置
本機不用裝任何依賴也能跑起來(下一步的Docker容器會自己處理)，這步只是讓IDE編輯`.py`檔案時有型別提示/自動完成，純前端(只改html/js)可以跳過。詳見[IDE型別提示設置](./IDE型別提示設置.md)。

## 啟動
1. 開啟Docker Desktop程式

2. 在終端啟動容器

記得要在inventory-management-system目錄下，執行：
```bash
docker compose up -d --build
```
會開始下載依賴和啟動容器，要等一段時間。

## 驗證
1. 開啟Docker Desktop，看有沒有叫做`inventory-management-system`的應用程式啟動，底下應該有`inventory`跟`vision-service`兩個容器，會亮綠燈。
2. 在瀏覽器輸入`http://localhost:5000`，應該會看到首頁。

## 之後每次開始工作前
目錄切到inventory-management-system，執行：
```bash
git pull
cd vision-service
git pull
cd ..
```
兩個repo都要同步到遠端，其他人可能有改。

## 每次修改後
目錄切到inventory-management-system，執行：
```bash
docker compose up -d --build
```
程式碼沒有自動同步進容器，要重新build才會生效。
