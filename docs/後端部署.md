# 後端部署(本機開發)

## 用手機透過區網存取 backend

`docker-compose.yml` 裡 `backend` 的 port 是 `"5000:5000"`,會綁到主機所有網卡(顯示成
`0.0.0.0:5000->5000/tcp`),不是只有 `127.0.0.1`,所以同一個區網下的手機理論上打得到——
但要用主機的**區網 IP**,不能用 `localhost`(手機打 `localhost` 指的是手機自己)。

容器內部查不到主機真正的區網 IP(container 裡看到的是 Docker 內部虛擬網卡位址),這件事
只能從主機端查。

### 查詢區網 IP(PowerShell)

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
    Where-Object { $_.IPAddress -notmatch '^(127\.|169\.254\.)' -and $_.InterfaceAlias -notmatch 'Loopback|vEthernet|WSL|Bluetooth' } |
    Select-Object InterfaceAlias, IPAddress
```

排除 `127.x`(loopback)、`169.254.x`(link-local,沒真的連上網路時作業系統自動配的假位址,
不是真正的區網 IP)、以及 Docker/WSL/藍牙的虛擬網卡,剩下的才是真正可以讓手機連過來的
位址(通常是 Wi-Fi 或乙太網路那張卡)。

手機瀏覽器打 `http://<查到的IP>:5000`,手機要跟這台電腦連同一個 Wi-Fi。

### 打不通:Windows 防火牆

Windows 防火牆預設會擋掉區網其他裝置連進來的請求(跟自己電腦用 `localhost` 存取不受影響
是兩回事)。用系統管理員權限開一條規則:

```powershell
New-NetFirewallRule -DisplayName "Docker backend 5000" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
```

規則建立後立即生效,不用重開機、不用重啟 Docker。
